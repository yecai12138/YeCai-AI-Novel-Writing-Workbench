# 文风统计（文风体检）判据表

> 这份文档不是介绍，是**规格**：`src-tauri/src/services/stylestat.rs` 的计数口径以它为准，
> `scripts/check-contracts.mjs` 会逐条比对这里的句式名与代码里的定义。
> 改任何一个正则、阈值、命名，都必须先改本文档 —— 顺序反了就是「实现驱动规格」，规格就失去意义。

## 0. 一条铁律：只出计数，不出评分

统计归代码，判断归模型与作者。这里所有输出都是「出现多少次」「占多少比例」，
不产生任何 0–100 分、等级、通过/不通过。理由：同一句式一章出现三五次时单章读起来都正常，
频率只有在**同一本书内纵向比较**才有意义；跨书比较会立刻变成对文风的独断评分。

因此以下写法在代码里是被禁止的（会体现在 review 上）：
- `StyleStats` 增加 `score` / `grade` / `level` 字段；
- `brief()` 里出现「建议改」「太差」「优秀」这类评价词；
- 前端把某项统计标成红色警告色（红＝结论，计数＝事实）。

## 1. 样本门槛

| 常量 | 值 | 含义 |
|---|---|---|
| `MIN_CHAPTERS` | 5 | 少于此章数直接返回 `None`，前端显示「样本不足」。2 章的数字会误导作者 |
| `PHRASE_WINDOW` | 20 | 高频短语只扫最近 20 章（近期口头禅比开篇更重要） |
| `REPEAT_MIN_CHARS` | 12 | 去标点后少于此长度的句子不算「重复句」（短句撞车太正常） |
| `SHORT_ENDING_CHARS` | 15 | 章末最后一行不超过此长度算「短结尾」（用于算占比） |

## 2. 句式 tic 判据（8 条，正则在 `pattern_defs()`）

命名用「判据」不用「错误」：命中不等于写得差，只等于这个形状出现了 N 次。

<!-- patterns:begin -->
| 句式名（代码里逐字一致） | 正则要点 | 为什么它值得数 |
|---|---|---|
| 矫正句「不是…而是…」 | `不是[^。！？\n]{1,24}?[，、]?(?:而)?是` | 单章一次显得有力，全书上百次就成了作者的口头禅 |
| 计时量词「X息 / X瞬」 | `[一两二三四五六七八九十几数半][息瞬]` | 「一息」「半瞬」是玄幻腔的默认节拍器，密集出现会显得敷衍 |
| 明喻「像一 / 仿佛 / 如同 / 宛如」 | `像一\|仿佛\|如同\|宛如` | 比喻的开关词；频次高说明比喻在替代描写 |
| 沉默节拍「沉默了 / 没有说话 / 没有回头」 | `沉默了\|没有说话\|没有回头` | 用动作沉默代替反应，重复即是套路 |
| 神态模板「眼中闪过 / 嘴角勾起 / 咬了咬唇」 | `眼[中底]闪过\|目光一凝\|瞳孔一缩\|眼眶微红\|嘴角[微轻一]?[勾扬翘]\|咬了咬唇\|不可置信` | 最容易固化的神态模板，跨书同质化极强 |
| 躯体反应「心头一紧 / 身子一颤 / 倒吸凉气」 | `心头一[紧沉颤]\|身子一[颤震僵]\|倒吸(?:了)?一口凉气` | 情绪靠生理反应代劳，次数过多会让角色失去内心 |
| 思维标记「心想 / 意识到 / 感到 / 觉得」 | `心想\|意识到\|感到\|觉得` | 心理动词直给，是「讲述」而非「呈现」的高频入口 |
| 抽象套话「一种说不出的 / 的意义在于」 | `一种说不出的\|说不清[的道]\|的意义在于\|真正的[^。！？\n]{1,10}是` | 用抽象词收尾，读起来像总结而不是场景 |

## 3. 其它口径

| 指标 | 口径 | 已知近似 |
|---|---|---|
| `topPhrases` | 最近 20 章内，汉字 3 字滑窗，滤掉含虚词的组合（`is_stop_gram`），出现 ≥3 次才上榜 | 只挖 3 字，抓不到 4–6 字的口头禅；角色名未单独排除 |
| `repeatedSentences` | 按句切分，去空白与中文标点后 ≥12 字，出现在 ≥2 章才算 | 同一句在同一章出现两次只算 1 章，避免复述被误判 |
| `ending.shortRatio` | 每章最后一个非空行长度 ≤15 字即算短结尾，算全书占比 | 不区分「有意为之的短句收束」与「偷懒」 |
| `ending.medianChars` | 各章末行字数的中位数 | 与短结尾占比一起看，单看任一项都会误读 |
| `titles` | 文件名里带「第N章」前缀 / 不带，各计一次 | 混用即报出两个非零值，用来抓机制痕迹 |

## 4. 注入位置与边界

- 组装点：`commands/ai.rs` 的 `apply_agent_prompt()` 末尾，仅当 `agent.target_dir` 为 `正文` 时追加；
- 形状：`stylestat::brief(&stats, 5)` 的纯文本，最后一行是请求「本章不要再复用这些句式与短语」；
- 边界：**统计结果只进 prompt，不进判定**。章节是否通过、要不要重写，仍由 Hook / 模型裁定；
  统计不构成任何阻断理由，否则会把「文风」变成机械门禁。
- 章数 < 5 时不注入（`stats_of` 返回 `None`），提示词里不会出现「样本不足」这种噪声。
